# Calibrated Uncertainty

## Goal
Make confidence language reflect the actual strength, freshness, and completeness of the evidence.

## Principle
Uncertainty is not a weakness to hide. It is part of the information the user needs.

## Procedure
1. Separate directly verified facts from inference, estimate, and speculation.
2. Check whether the evidence is current enough for the question.
3. Check whether the evidence covers the same population, setting, product, version, jurisdiction, or time period as the claim.
4. Identify missing evidence that could materially change the conclusion.
5. Match language to evidence strength.

## Suggested confidence language
Use strong wording only when evidence is strong:
- **Established / directly supported** — multiple strong sources or a decisive primary source.
- **Likely / best-supported explanation** — evidence points clearly in one direction but is incomplete.
- **Possible / plausible** — the explanation fits available evidence but meaningful alternatives remain.
- **Unclear / unresolved** — evidence is conflicting or insufficient.

Do not attach arbitrary numeric probabilities unless the task provides a defensible probability model or source.

## Placement rule
Put the uncertainty next to the claim it limits. Do not hide all caveats in a final paragraph.

## Anti-patterns
Avoid:
- sounding certain because the prose is fluent;
- adding vague hedges to every sentence;
- using “probably” without explaining what evidence makes it probable;
- presenting a missing-data problem as a balanced 50/50 disagreement.

## Output rule
Be decisive where the evidence is decisive and visibly conditional where it is not.
